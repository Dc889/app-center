# 插件模块脱敏联调样例

供能力组对照。样例不含包正文、实例凭证或工作区密钥。

| 场景 | 角色与状态 | 字段来源 | 预期下发 |
| --- | --- | --- | --- |
| PLG-01 上架 | 用户上传并提交后待受理；运维决定对外权限后执行 | 包标识、版本、依赖来自扫描结果；说明、权限、网络清单来自申请 | 批准后 `publish_package` 一次，不直接安装 |
| PLG-02 版本再审 | 用户提交待受理；运维选择升级策略和对外权限 | 原版本和原指纹来自执行依据；新版本来自新包 | 批准后 `revise_package` 一次。包身份不一致时拒绝 |
| PLG-03 安装/升级/卸载 | 仓库先选工作区。免审即办，需审批则待受理。未采集安装状态不能当成未安装 | 工作区来自当前会话可配置目录；实例 ID、原版本和目标指纹来自操作依据 | 每个获准动作各下发一次：`install`、`upgrade` 或 `uninstall`。切区后不得沿用旧实例 |
| PLG-04 自动禁用 | 只由告警创建。运维提交恢复后进入观察 | 实例、采样和阈值来自告警；恢复说明和附件来自运维 | 禁用 `disable_plugin` 一次；恢复 `restore_plugin` 一次。观察失败才再次禁用，不重放已成功节点 |

验收命令：`npm.cmd run test:module -- plugins` 与 `npm.cmd run test:browser -- plugins`。真实 Dify 安装和定向禁用仍待能力组联调。
