# 安全事件模块脱敏联调样例

供能力组对照。EVT-01 本身不下发执行。副作用只出现在已关联且同对象成功的业务工单上。

| 场景 | 角色与状态 | 字段来源 | 预期下发 |
| --- | --- | --- | --- |
| 人工报告 | 用户提交后为未研判 | 对象类型、对象标识和事实说明来自申请；告警编号和原始级别由管理端生成 | 零次 |
| 研判与处置 | 运维甲开始处置，填写动作和结果后提交复核 | 级别、结论、根因和影响范围来自研判；附件只保存证据 ID、文件名和摘要 | 零次。禁用、停用、隔离、下架、撤销必须先有同对象成功的关联工单 |
| 关联处置草稿 | 运维在处理中选择动作后创建对应草稿 | 对象 ID 来自事件；KB-05、MCP-03、AG-05、KEY-02 只预填可编辑字段。插件禁用仍走 PLG-04 告警，不从事件新建 | 创建草稿零次。草稿随后按该工单自己的规则下发 |
| 双人关闭 | 另一名运维复核后关闭。同一人不能关闭自己办理的事件 | 复核意见来自第二名运维 | 零次 |

验收命令：`npm.cmd run test:module -- events` 与 `npm.cmd run test:browser -- events`。原始指标、日志和产品侧处置仍待能力组提供。
