# MCP 模块脱敏联调样例

供能力组对照。仓库和普通用户响应不包含统一 URL、指纹原文或 provider 凭证。

| 场景 | 角色与状态 | 字段来源 | 预期下发 |
| --- | --- | --- | --- |
| MCP-01 上架登记 | 用户选择技术注册后待受理；运维安全复核后执行 | 注册 ID、传输方式和工具清单来自技术注册快照；名称、用途、边界来自申请 | 批准后 `register_mcp` 一次。地址由服务端重读，不采用手填 URL |
| MCP-02 绑定 | 仓库先选工作区。本人私有且符合边界可即办，其余待受理 | 工作区来自会话；期限来自申请；指纹由绑定依据重读，不回给普通页面 | `bind` 一次。未选工作区不能展示绑定状态 |
| MCP-03 解绑/隔离/下架 | 运维按动作选择目录和绑定范围后执行 | 动作资格和绑定清单来自处置依据；单用户只冻结所选账户和工作区 | 每个获准动作一次：`unbind_mcp`、`isolate_mcp` 或 `withdraw_mcp`。清单不完整时零次 |

验收命令：`npm.cmd run test:module -- mcp` 与 `npm.cmd run test:browser -- mcp`。真实绑定和共享 provider 撤权仍待能力组联调。
