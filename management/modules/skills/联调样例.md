# Skill 模块脱敏联调样例

供能力组对照。样例不含真实凭证、人员身份证号或文件正文。管理端页面只提交申请和查询，不直连产品。

| 场景 | 角色与状态 | 字段来源 | 预期下发 |
| --- | --- | --- | --- |
| SKL-01 上架 | 用户提交后为待受理；运维批准后执行 | `intakeId`、名称、版本、说明、许可证、范围来自申请表；摘要和扫描结论由上传接口重读 | 批准后 `publish_skill` 一次。驳回、扫描未通过为零次 |
| SKL-02 版本再审 | 用户提交待受理；运维选择历史版本策略后执行 | 原版本号和原摘要来自执行依据；新版本和新摘要来自新的待审包 | 批准后 `revise_skill` 一次。原版本未变或摘要变化时拒绝，零次 |
| SKL-03 下载 | 有下载权的用户从仓库或手工申请即办 | 版本和 SHA-256 来自所选目录版本；账户和组织来自会话 | `download` 一次。领取完整文件后回执一次；中断不回执。下架项不能新建下载 |
| SKL-04 下架 | 运维审批后按生效时间执行 | 目录 ID、版本、历史下载统计来自下架依据；原因和生效时间来自申请 | 到点 `withdraw_skill` 一次。交付未核对前不下发 |

验收命令：`npm.cmd run test:module -- skills` 与 `npm.cmd run test:browser -- skills`。模拟对端通过不算真实仓库联调。
