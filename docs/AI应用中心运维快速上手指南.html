运维人员日常使用指南（4 步核心工作流）

1每日运行巡检（左侧「运行监控」）

  • 服务监控（/service-monitor）：查看宿主机 ecs-5e28 CPU、内存、磁盘及 11 个 Dify 容器实时状态与资源消耗；容器异常时可执行受控重启。
  • 资源资产监控：查看智能体、知识库、插件、MCP、Skill 的全量纳管明细与调用记录。
  • 租户与模型监控（/tenant-model-monitor）：按账号全景查看每人名下的应用、知识库、插件、MCP 数量及本月 Token 消耗；点击「查看模型额度」自动定位至该工作区模型台账。

2办理工单审批（左侧「工单中心 → 我的待办」）

  • 受理并审批业务用户提交的知识库上架/绑定（KB-*）、智能体发布/授权/下架（AG-*）、API 密钥申领/吊销（KEY-*）、插件安装（PLG-*）、MCP 绑定/隔离（MCP-*）、Skill 上架/下架（SKL-*）工单。
  • 审批通过后，系统自动调用底层 Dify 接口真实下发并回写执行回执，无需人工登录 Dify 手工操作。

3旁路对账与安全处置（左侧「运行监控 → 安全事件」）

  • 在「安全事件」页顶部点击「立即重新对账」，自动比对 Dify 只读库与应用中心审批台账，识别绕过审批私自安装的插件、绑定的 MCP、生成的密钥、开放共享的知识库及私自修改的已发布应用。
  • 对检出的异常点击「转安全事件单」（支持批量建单），按「未研判 → 处理中 → 待复核 → 双人复核关闭」完成安全闭环。

4模型额度熔断与账号生命周期管控

  • 模型限额与自动禁用：在「租户与模型监控」发起 MOD-01 工单并审批生效；系统每 60 秒自动巡检消耗，达到 100% 自动在 Dify 禁用该工作区的对应模型，用户提交调额单审批通过后自动解禁。
  • 离职交接与有效期回收：在「账号与集成」页签中审批员工提交的 ACC-03 资源交接单、ACC-04 组织角色变更单，并对临期/已过期的密钥与共享授权执行续期或一键回收。
