# 应用中心全量开发计划

本次交付以[总设计正文第 4 节](../分工文档/总设计.md)为工单发布、接口版本和扩展规则。管理组与能力组使用同一份契约并行实现全部功能。下表按类型列出本次完整范围，详细字段、触发条件和成功判据逐行对应[执行路由](../分工文档/能力组件开发.md#7-全部工单的执行路由)。

管理组交付每种工单的申请、字段校验、审批、分支选择、下发、结果回写及角色可见范围，同时完成类型管理、四个仓库页、九个监控页、审计和告警。能力组交付全部执行动作、四库读写、产品适配、权限复核、运行与观测接口，以及重启恢复和结果查证。共享契约的提供方和调用方共同维护对应样例。

验收按每个动作及条件分支记录成功、拒绝、重复投递、下游失败、结果未知和恢复后的实际行为。每页核对数据来源及权限。外部部署未验证或缺少所需 API 的分支记录具体缺口，继续计为未完成。模拟通过、接口已登记或已有单条闭环均不能替代全量验收。当前实现进度见总设计第 1 节。
